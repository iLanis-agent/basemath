Base Math

255 and ff are the same number wearing different digits.

Boundary: arithmetic only Base Math works out whole numbers written in other bases, two's complement patterns and digit capacities from the numbers you type. It does not know which base, width or signed format a language, file or device uses. Check those where they apply.

The convert truth

ff in base 16 is 255 in base 10.

The twos truth

-5 fits in 8 bits as 11111011 (hex fb). Read as an unsigned number, that pattern is 251.

The capacity truth

8 digits in base 2 hold 0 to 255, which is 256 values.
